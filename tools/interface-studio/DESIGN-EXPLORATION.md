# Визуальный вариант: прохладный светлый интерфейс

Этот вариант применён только к прототипу и предлагается для визуального обсуждения. Согласованная отправная точка сохранена в Git как `design-baseline-2026-10-28`.

## Ориентиры

- [ChatGPT: визуальные настройки](https://help.openai.com/en/articles/11958281-updating-your-visual-experience-on-chatgpt) — акцентный цвет может связывать сообщения, кнопки и выделение; внимание к контрасту и настройкам внешнего вида.
- [Google Gemini: Neural Expressive](https://blog.google/innovation-and-ai/products/gemini-app/next-evolution-gemini-app/) — выразительность через цвет и типографику. Здесь цвет используется спокойнее, чтобы сохранить удобство длительного чтения и ранее согласованное отсутствие лишних анимаций.
- [OpenAI: рекомендации по визуальному интерфейсу](https://developers.openai.com/plugins/concepts/ui-guidelines) — визуальные элементы должны поддерживать разговор, а не перегружать его дополнительными контейнерами и управлением.

## Решение для OpenBot

Светлые холодные поверхности и мягкое разделение областей, более ясное выделение активного агента его цветом, нейтральное облако ответа, мягкая рамка и тень поля ввода, а также согласованные оттенки текста и иконок. Структура экрана, действующие принципы, Alegreya Sans, ограничение ширины переписки и логика чата сохранены. Палитра применяется только к светлой теме главного экрана прототипа.
