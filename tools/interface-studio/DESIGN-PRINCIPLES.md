# Принципы интерфейса OpenBot

Согласованы для пользовательской версии интерфейса. Сохраняйте этот файл при синхронизации с оригинальным OpenBot. При переносе изменений проверяйте эти принципы на затронутых экранах и в разных состояниях.

## Курсор

- Обычная стрелка используется над всеми элементами интерфейса, включая пункты меню, кнопки, текст, поля ввода и элементы списков.
- Курсор-рука (`pointer`) используется только над ссылками и их содержимым.
- Стрелка над полем ввода не отменяет текстовую каретку при вводе и не меняет поведение редактирования.

## Наведение

- У элементов списка агентов нет отдельного визуального эффекта при наведении. Это относится и к закреплённым агентам.
- Выбранный агент остаётся визуально выделенным при наведении и без него. Видимая индикация фокуса для клавиатуры сохраняется.
- Эффекты наведения использовать только там, где они нужны для ориентации: пункты меню и кнопки панелей инструментов. Не добавлять их ради украшения.

## Применение

Текущая реализация находится в `src/renderer/stories/design-main-screen.css` и действует в прототипе главного экрана. Это не изменение рабочего приложения. При переносе в приложение необходимо применить принципы к соответствующим компонентам и проверить остальные состояния и экраны.
